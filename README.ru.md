## 📖 О проекте

**Posluchac** (*послушак*) — это лёгкий и функциональный музыкальный плеер для Windows, разработанный на связке **Go (Wails v2)** и **Vue 3**. Приложение позволяет находить музыку на торрент-трекерах, мгновенно слушать треки онлайн через последовательную потоковую загрузку прямо из сети BitTorrent, выборочно скачивать отдельные песни или альбомы целиком, а также организовывать локальную музыкальную библиотеку с автоматическим извлечением тегов и обложек.

## ✨ Возможности

### 🔍 Поиск по торрентам и модульные источники
* **Пользовательские JSON-источники**: возможность подключать и настраивать собственные каталоги и поисковые индексы (например, из [rutracker-music-links](https://github.com/Miffle/rutracker-music-links/tree/main)).
* **Инспектор содержимого**: просмотр структуры файлов торрента, аудиоформатов (MP3, FLAC, OGG, WAV, M4A, AAC) и битрейта до начала загрузки.

### ⚡ Потоковое воспроизведение (Streaming Preview)
* **Последовательное воспроизведение (Sequential Streaming)**: прослушивание композиций без ожидания завершения скачивания всего торрента или файла.
* **Встроенный HTTP-прокси**: приоритетная доставка аудиофрагментов для непрерывного воспроизведения без задержек.

### 📥 Управление загрузками и раздачами
* **Выборочное скачивание**: возможность выбрать конкретные композиции из альбома или дискографии.
* **Фоновая раздача и мониторинг**: отображение текущей скорости отдачи и загрузки, количества активных пиров и прогресса.
* **Гибкое удаление**: удаление раздачи с сохранением файлов на диске либо с полной очисткой.

### 📚 Библиотека и автоматические теги
* **Автоматическое сканирование**: индексация папки с музыкой при запуске и по кнопке обновления.
* **Чтение ID3-метаданных**: автоматическое определение исполнителя, альбома, года, жанра, длительности и обложки.
* **Организация дискографии**: группировка по артистам, альбомам и отдельным синглам.
* **Избранное и плейлисты**: добавление треков в любимые (❤️), создание собственных плейлистов и управление ими.

### 🎛️ Плеер и интеграция с Windows
* **Режимы воспроизведения**: повтор одного трека, повтор плейлиста, случайный порядок (перемешивание по алгоритму Fisher-Yates).
* **MediaSession API**: управление с мультимедийных клавиш клавиатуры (Play/Pause, Next, Prev) и системный оверлей Windows.
* **Полноэкранный режим обложки**: стильный режим отображения виниловой пластинки на весь экран с элементами управления (`Esc` для выхода).

### 🔕 Системный трей Windows
* **Сворачивание / закрытие в трей**: приложение продолжает играть в фоне при закрытии окна.
* **Восстановление по клику**: разворачивание окна по клику левой кнопкой мыши на иконку в области уведомлений.
* **Нативное контекстное меню**: меню правой кнопки мыши («Открыть Послушак» и «Выйти») для полного и чистого завершения процесса без зависания в диспетчере задач.

### 🌐 Локализация и обновления
* **Двуязычный интерфейс (RU / EN)**: полноценный перевод всех экранов, модальных окон и подсказок с переключением на лету в Настройках.
* **Встроенный автоапдейтер**: проверка обновлений на GitHub Releases, скачивание и бесшовный перезапуск приложения.

## 📥 Установка

Posluchac распространяется как **портативное автономное Windows-приложение** (не требует установки и прав администратора).

1. Перейдите на страницу [**Последнего релиза**](https://github.com/Miffle/Posluchac/releases/latest).
2. Скачайте файл `Posluchac.exe` (или архив `.zip`).
3. Поместите `Posluchac.exe` в удобную папку (например, `C:\Users\<Имя>\AppData\Local\Programs\Posluchac` или на Рабочий стол) и запустите.

> [!NOTE]
> Для работы приложения требуется **Windows 10 (версия 1803+)** или **Windows 11** со встроенным компонентом **Microsoft Edge WebView2** (установлен по умолчанию во всех современных версиях Windows).

## 📡 Источники музыки (JSON)

Для поиска музыки Posluchac использует внешние JSON-источники раздач.

Готовый каталог музыки с RuTracker находится в репозитории [**Miffle/rutracker-music-links**](https://github.com/Miffle/rutracker-music-links/tree/main).

### Как добавить источник в плеер:
1. Перейдите в репозиторий [rutracker-music-links](https://github.com/Miffle/rutracker-music-links/tree/main).
2. Откройте JSON-файл (например, [`rutracker-music.json`](https://github.com/Miffle/rutracker-music-links/blob/main/rutracker-music.json)) и нажмите кнопку **Raw** (или скопируйте прямую ссылку на сырой файл).
   * Прямая ссылка: `https://raw.githubusercontent.com/Miffle/rutracker-music-links/main/rutracker-music.json`
3. В приложении Posluchac откройте страницу **«Поиск»** и нажмите кнопку **«Источники»** в верхней части экрана.
4. Вставьте скопированную ссылку в строку ввода и нажмите **«Добавить»**.
5. Релизы загрузятся в локальную базу данных и сразу появятся в поиске.

> [!TIP]
> **Расширение базы через Pull Request:**
> Вы можете пополнять каталог новыми раздачами и исполнителями! Для этого делайте Fork репозитория [rutracker-music-links](https://github.com/Miffle/rutracker-music-links/tree/main), добавляйте новые раздачи в JSON-файл и отправляйте изменения через **Pull Request (PR)**.

## 🛠️ Сборка из исходников

### Требования
* **Go**: версия 1.23 или новее ([Скачать Go](https://go.dev/dl/))
* **Node.js**: версия 20 или новее с `npm` ([Скачать Node.js](https://nodejs.org/))
* **Wails CLI**: устанавливается одной командой:
  ```bash
  go install github.com/wailsapp/wails/v2/cmd/wails@latest
  ```

### Клонирование и запуск в режиме разработки
```bash
# Клонирование репозитория
git clone https://github.com/Miffle/Posluchac.git
cd Posluchac

# Установка зависимостей фронтенда
cd frontend
npm install
cd ..

# Запуск Wails в режиме разработки с горячей перезагрузкой (hot-reload)
wails dev
```

### Релизная сборка
Для сборки компактного оптимизированного исполняемого файла `.exe`:
```bash
wails build -s -platform windows/amd64 -tags disable_libutp
```
Готовый бинарник будет находиться по пути:
```text
build/bin/Posluchac.exe
```

## ⚙️ Настройки и хранение данных

* **База данных и кэш**: сохраняются в домашней директории пользователя:
  ```text
  %USERPROFILE%\.posluchac\
    ├── library.db       # База данных SQLite (треки, плейлисты, избранное)
    ├── covers\          # Кэшированные обложки альбомов
    └── torrents\        # Служебные данные торрент-движка и возобновления
  ```
* **Папка загрузок**: настраивается на вкладке **Настройки** (по умолчанию `%USERPROFILE%\Music\Posluchac` или `%USERPROFILE%\Downloads\Posluchac`).

## 🧩 Стек технологий

| Компонент | Технология | Описание |
|---|---|---|
| **GUI-фреймворк** | [Wails v2](https://wails.io/) | Легковесный мост между Go и WebView |
| **Интерфейс** | [Vue 3](https://vuejs.org/) + [TypeScript](https://www.typescriptlang.org/) | Реактивный UI, Pinia стейт-менеджмент, Vite |
| **Торрент-движок** | [anacrolix/torrent](https://github.com/anacrolix/torrent) | BitTorrent-клиент на чистом Go с поддержкой sequential priority |
| **Парсинг метаданных** | [bogem/id3v2](https://github.com/bogem/id3v2), [dhowden/tag](https://github.com/dhowden/tag) | Чтение тегов ID3v1/v2, FLAC, OGG, MP4 и извлечение картинок |
| **Хранилище** | [modernc.org/sqlite](https://gitlab.com/cznic/sqlite) | Встраиваемый SQLite без CGO |
| **Системный трей** | Win32 Shell API (`Shell_NotifyIconW`) | Чёткая иконка под High-DPI, цикл сообщений, нативное меню |
| **CI / CD** | GitHub Actions | Автоматическая сборка, генерация чейнджлога, публикация в Discord |
